# Reference Portfolio Coverage Map

This map records which deliverable patterns from the three supplied project folders were rebuilt for the NawaCloud fictional SaaS case. The content, company identity, explanations, decisions, scenarios, evidence labels, and presentation are tailored to this new portfolio.

## Project 1 — modular ISMS toolkit

Its twelve workstreams are represented: gap assessment, Statement of Applicability, risk register, scope and context, asset inventory, business continuity and disaster recovery, policies and procedures, awareness and training, management review, implementation/risk checklists, internal audit, and ROI. The package includes both editable workbooks and explanatory documents where useful.

## Project 2 — security control implementation set

The rebuilt package covers the 93-reference control applicability register, linked risk and asset registers, gap remediation, policy and procedure drafts, evidence templates, audit procedures, and management-facing charts in the executive deck. Control descriptions and rationale are written for the NawaCloud scenario; simulated states are clearly labeled.

## Project 3 — implementation simulation

The fictional organization case, defined scope, gap assessment, core documentation pack, and board-level briefing format are represented through NawaCloud's SaaS scenario, executive overview, gap report, policy pack, treatment records, and executive presentation. The reference healthcare organization and its context were not carried into the new scenario.

## Practical exercises

Six case exercises apply the portfolio to identity compromise, tenant isolation, restoration, supplier access, awareness, and audit sampling. Each has learner tasks and facilitator guidance. All are fictional and use synthetic examples.

The original projects served as structural references. This portfolio's examples are not presented as records or results from an operating organization.
