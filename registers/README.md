# Register Data Files

These CSV files are editable source registers for the NawaCloud educational simulation. They contain fictional organizations, assets, risks, status assumptions, and evidence references only. Use the polished Excel workbooks in `../deliverables/workbooks/` for review; use these CSV files when you need to inspect or reuse the underlying tabular records.
