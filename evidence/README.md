# Evidence Guide

This repository contains fictional evidence identifiers and clearly labeled placeholders only. It does not contain real customer, employee, supplier, production, or security-event records.

Use identifiers such as EV-IAM-01 or EV-BCP-01 to connect an audit procedure to a simulated evidence type. Never present these placeholders as evidence collected from an operating organization. For real evidence, obtain authorization, minimize personal and sensitive content, record provenance and date, restrict access, and apply retention requirements.
